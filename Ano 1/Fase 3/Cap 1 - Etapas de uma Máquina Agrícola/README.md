## 📜 Descrição

Este projeto é a entrega da **Fase 3, Capítulo 1: Etapas de uma Máquina Agrícola**. O objetivo foi construir um pipeline de Engenharia de Dados (ETL) completo, focado nos requisitos obrigatórios da atividade.

A aplicação simula os dados de sensores de IoT (baseados no projeto Wokwi da FASE 2) e persiste essas informações em um banco de dados relacional Oracle. O entregável principal é um Jupyter Notebook que serve como relatório de execução, documentando todo o processo.

O fluxo de trabalho seguido foi:
1.  **Criação da Tabela:** Definição e criação da tabela `SENSORES` no Oracle SQL Developer.
2.  **Extração (Extract):** Simulação de 100 leituras de sensores (N, P, K, pH, Umidade, Temperatura) usando Python.
3.  **Transformação (Transform):** Formatação dos dados em um DataFrame do Pandas.
4.  **Carga (Load):** Inserção em lote (bulk insert) dos 100 registros na tabela `SENSORES` do Oracle.
5.  **Verificação:** Execução de consultas SQL (via Python) para validar e analisar os dados persistidos, cumprindo o requisito de "prints de tela das consultas".

### Pré-requisitos
- Python 3.x instalado.
- Acesso a um ambiente de banco de dados Oracle.
- Bibliotecas Python instaladas: `jupyter`, `pandas`, `oracledb`.

### 1. Instalar Dependências
No terminal, instale as bibliotecas necessárias:

```bash 
pip install jupyter pandas oracledb
```

### 2. Configurar o Banco de Dados
A estrutura da tabela precisa ser criada no seu ambiente Oracle.

Execute o script SQL (disponível na seção 'Estrutura do Banco de Dados' abaixo) em sua ferramenta de gerenciamento Oracle (como Oracle SQL Developer) para criar a tabela SENSORES.

### 3. Configurar a Conexão
Abra o arquivo db_operations.py.

Insira suas credenciais de acesso ao Oracle nas variáveis DB_USER, DB_PASSWORD e DB_DSN.

### 4. Executar a Aplicação
Abra o arquivo AlanRobinSantos_RM567437_e_LucasAmorim_RM567505_fase3_cap1.ipynb no VSCode.

Execute as células de código na ordem (de cima para baixo). O notebook irá simular os dados, carregá-los no Oracle e, em seguida, executar as consultas de verificação.

## 🗄️ Estrutura do Banco de Dados (Schema)
A tabela utilizada para persistir os dados é a SENSORES, definida pelo seguinte comando SQL (executado no Oracle SQL Developer):

```bash
CREATE TABLE SENSORES (
    id NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    data_leitura TIMESTAMP,
    N_status NUMBER(1),
    P_status NUMBER(1),
    K_status NUMBER(1),
    PH_SOLO NUMBER(4, 2),
    UMIDADE_SOLO NUMBER(5, 2),
    TEMPERATURA NUMBER(4, 2)
);
```
